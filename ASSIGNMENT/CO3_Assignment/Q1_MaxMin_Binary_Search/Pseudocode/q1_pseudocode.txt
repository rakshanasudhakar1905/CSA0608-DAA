MAX-MIN D&C:
1. If one element, return it as both minimum and maximum.
2. If two elements, compare once and return smaller and larger.
3. Otherwise divide the array into two halves.
4. Recursively obtain (minimum, maximum) from both halves.
5. Compare the two minima and the two maxima; return combined result.

BINARY SEARCH:
1. Set low=0 and high=n-1.
2. While low <= high, find mid.
3. If a[mid] equals target, return mid.
4. If target is smaller, set high=mid-1; otherwise set low=mid+1.
5. If the loop ends, return not found.
