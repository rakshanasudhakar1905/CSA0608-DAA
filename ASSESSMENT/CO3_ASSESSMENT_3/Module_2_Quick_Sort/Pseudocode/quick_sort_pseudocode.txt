QUICK_SORT(A, low, high)
1. If low < high:
2.    Choose a pivot using median-of-three (first, middle, last)
3.    Move pivot to the end
4.    p = PARTITION(A, low, high)
5.    QUICK_SORT(A, low, p-1)
6.    QUICK_SORT(A, p+1, high)

PARTITION(A, low, high)
1. pivot = A[high]
2. i = low - 1
3. For j from low to high-1:
4.    If A[j] <= pivot: increment i; swap A[i], A[j]
5. Swap A[i+1], A[high]
6. Return i+1
